NuPhy Air60 V2 – Vial flasher

Backs up and flashes the keyboard's main MCU (STM32F072) from the browser. The radio module and the 2.4 GHz dongle are never touched.

Experimental. It has been tried once on a real keyboard (backup and flash of firmware v3 worked); the image checks are also unit-tested. Always keep the backup it makes. Going back to stock is always possible from the DFU mode (hold Esc while plugging in).

This browser has no WebUSB. Use Chrome, Edge or Opera on a computer.

1. Put the keyboard in DFU mode

Unplug the USB cable, hold Esc, plug it back in, then release. Then connect:

Not connected.

Windows needs the WinUSB driver for 0483:df11 (for instance with Zadig); Linux needs a udev rule for it.

2. Back up the current firmware

Reads the 128 KB of flash twice and checks that both reads are identical. Required before flashing.

Save backup file

3. Choose the firmware

Where do I get NuPhy's official firmware, to go back to stock?
  1. Open nuphy.com/pages/firmwares and download the QMK firmware for the Air60 V2 (the .bin; it is NuPhy's file, so it is not hosted here).
  2. Choose that file above. The page checks it like any other image.
  3. NuPhy's RF and dongle updates are separate and are never needed to go back: this tool does not touch them. Your own backup from step 2 restores exactly what you had.

4. Flash

The keymap, side-light and sleep settings are reset on the first boot after a different firmware (the EEPROM layout changes).
